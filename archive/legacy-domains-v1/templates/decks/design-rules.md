## Chart Rules

- Treat charts as editorial slide components, not plotting-library screenshots.
- Prefer native editable PowerPoint charts or shapes; use SVG second and PNG only as a documented fallback.
- Use one accent color for the insight and muted colors for context.
- Remove default chart borders, spines, backgrounds, and nonessential gridlines.
- Use direct labels when they can replace a legend.
- Do not repeat the slide conclusion as an internal chart title.
- Size labels for projection and format units consistently.
- Sort categories when order improves comprehension.
- Start quantitative bar axes at zero unless the exception is explicitly justified.
