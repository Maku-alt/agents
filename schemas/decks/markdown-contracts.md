# Deck Markdown Contracts

These contracts define the required sections for Markdown artifacts.
Section text may be concise, but required headings must not be omitted.

## `storyline.md`

Required headings:

- `# Storyline`
- `## Working Thesis`
- `## Audience And Decision Context`
- `## Narrative Arc`
- `## Closing Intent`
- `## Unresolved Assumptions Or Weak Points`

## `style-preview-set.md`

Required headings:

- `# Style Preview Set`
- a heading beginning with `## Option A`
- a heading beginning with `## Option B`
- a heading beginning with `## Option C`
- `## Recommendation`

Each option must define vibe, palette, typography, composition, signature elements, fit, and primary risk.

## `design-rules.md`

Required headings:

- `# Design Rules`
- `## Hierarchy Rules`
- `## Spacing Rules`
- `## Title Behavior`
- `## Chart Rules`
- `## Table Rules`
- `## Image Rules`
- `## Closing Slide Rules`
- `## Anti-Patterns To Avoid`

## `visual-brief.md`

Required fields:

- `overall_visual_logic`
- `visual_intensity_level`
- `slide_families_with_visual_support`
- `slide_families_without_visual_support`
- `metaphor_strategy`
- `icon_guidance`
- `diagram_guidance`
- `image_usage_guardrails`

## `closing-slide-brief.md`

Required fields:

- `thesis_to_amplify`
- `final_message`
- `emotional_tone`
- `candidate_metaphors`
- `recommended_direction`
- `composition_notes`
- `avoid`

Optional fields:

- `quote_and_author`
- `image_prompt`

## `review-report.md`

Required headings:

- `# Review Report`
- `## Overall Verdict`
- `## Strongest Aspects`
- `## Priority Findings`
- `## Readiness Assessment`
- `## Recommended Next Step`

## `style-preset-catalog.md`

Required headings:

- `# PPT Style Preset Catalog`
- `## How To Use`

Each preset must define mood, best fit, PPT translation, and risk.
